### How to fill a row (takes 2 minutes each)
1. Open your Sketchfab library / download history, find the model, copy Title, Author, License, URL.
2. Best way: put the original .glb in reference/sketchfab/ and run `python3 tools/extract_credits.py`.
   It reads the license from the file and writes CREDITS.md + assets/credits.txt (shown in-game) automatically.
3. No .glb? Add one line to tools/extra_credits.txt: `Title | Author | License | URL`.
4. Verdict: CC0 / CC-BY = OK. CC-BY-SA = CHECK. NC / ND / Editorial / Standard / no license / ripped from a game = STOP, replace it.
   (The app has ads and the models are modified, so NC and ND are not allowed.)
5. Free replacements with clear licenses: Kenney.nl (CC0), Quaternius (CC0), Poly Pizza, OpenGameArt.
